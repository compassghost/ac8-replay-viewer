ACE COMBAT 8 Replay Viewer

A self-service tactical replay viewer. Convert your own replay saves on your own computer, then watch them in 3D with kill tracking and projectiles. Nothing is uploaded anywhere.

Open the viewer (sample missions)
Your replays stay on your computer. Saves are converted locally by scripts you can read (Python standard library only), and the viewer runs in your browser without uploading anything. A content security policy in the page blocks requests to any other site. Don't send your .sav files to anyone else's converter. This hosted page is a preview of the sample missions; run the package locally for your own replays.

Use your own replays

The viewer is self-service: you bring the save, your machine does the conversion.

  1. Download this package and unzip it. You need Python 3.10+ (no extra packages).
  2. Convert a save. Replays live in %LOCALAPPDATA%\BANDAI NAMCO Entertainment\ACE COMBAT 8\Saved\SaveGames. The original is never modified. Make a copy of any replays so you don't lose them. The game automatically deletes old saves automatically! 
    python ac8_replay.py "...\Replay5.sav" --export Replay5.json
python attribute_kills.py "...\Replay5.sav" Replay5.json
python add_missiles.py "...\Replay5.sav" Replay5.json
python round_export.py Replay5.json --no-backup
python build_index.py --default Replay5.json
  3. Serve and open. 
    python -m http.server 5678
    Then browse to http://localhost:5678/. Or skip the server and use Open replay JSON in the viewer to load a converted file by hand.

Mission number = Mission ID − 1. See RUNBOOK.md for details and video rendering.
